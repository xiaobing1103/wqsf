企业服务首页

  • 点击“开始报单”进入服务选择。
  • 点击当前报单进入资料或进度详情。

交互规则

  • 顶部开关切换知识产权与资质申报。
  • 提交前确认服务协议与隐私政策。
  • 该流程不要求征信、网银、开票或身份证资料。

文件规则
FILE & EXPORT RULES

上传、存储、审核与导出规则

业务数据库只保存文件元数据和访问关系，原始文件进入私有对象存储。

类型建议格式上传与校验存储与访问导出规则
图片JPG / PNG校验 MIME、大小与清晰度；失败支持单项重试私有存储，预览使用短时签名地址保留原格式进入 ZIP
文档PDF / XLSX校验扩展名与实际内容；限制可执行内容原件不可通过公开 URL 访问审核表单独生成 XLSX
视频MP4显示上传进度，支持大文件分片与续传对象存储按报单和资料项隔离办公室视频进入受控 ZIP
文字结构化字段 / URL必填、长度、格式和 URL 合法性校验数据库加密或脱敏展示敏感字段开票信息写入审核表
01目录命名

企业名称_报单编号_资料包.zip；内部按 01–11 固定编号，方便人工核对。

02两类出口

Excel 只含结构化审核结果；ZIP 包含原始文件，必须分开授权。

03生命周期

安全说明
SECURITY & PRIVACY

敏感资料的受控预览与留痕

身份证、征信、网银、基本户等资料不在公共链路裸露，不默认进入普通数据导出。

01

最小权限

按角色、业务范围和报单归属授权。普通运营可看状态，不代表可看原件；ZIP 导出单独配置角色权限。

02

受控预览

敏感文件通过服务端鉴权后签发短时地址；前端不保存长期链接，预览页面可增加动态水印。

03

传输与存储

全链路 HTTPS；对象存储私有桶；数据库仅保存元数据。基本户等结构化敏感字段建议应用层加密。

04

审计与追溯

记录查看、下载、审核、导出、失败重试和权限变更，包含操作人、时间、报单号、结果与来源。

评审稿数据原则所有截图均使用模拟企业、脱敏手机号、脱敏税号和脱敏账号，不包含真实身份证、征信或银行资料。
