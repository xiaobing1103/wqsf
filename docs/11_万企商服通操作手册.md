## 1. 系统入口与岗位

### 1.1 入口

| 入口 | 本地调试地址 | 用途 |
| --- | --- | --- |
| 管理后台 | http://127.0.0.1:5174 | 客户维护、报单审核办理、导出、团队和开关管理 |
| 小程序H5 | http://127.0.0.1:5175/#/ | 在电脑浏览器体验客户端业务流程，不等于微信真机 |
| 后端健康检查 | http://127.0.0.1:8080/actuator/health | 返回status为UP表示后端健康检查通过，不代表全部业务验证通过 |

这些是本机地址，不是线上客户访问地址。在其他电脑或手机上，127.0.0.1指向设备自身；本地真机联调由维护人员配置局域网API和文件访问地址。正式地址由部署负责人提供。

### 1.2 谁使用哪个账号

| 岗位 | 主要职责 | 注意事项 |
| --- | --- | --- |
| 企业客户 | 小程序登录、填写资料、提交报单、补件、查看进度 | 使用后台发放的客户账号，只访问有权关联的企业 |
| 运营人员 | 客户维护、业务跟进、导入和资料导出等授权操作 | 不应使用超级管理员账号代替日常岗位账号 |
| 审核人员 | 受控查看资料、逐项审核、退回补充、办理状态处理 | 敏感资料和具体按钮仍按后端权限校验 |
| 超级管理员（SUPER_ADMIN） | 团队角色、客户删除、全部功能开关及其他管理操作 | 角色以实际账号配置为准，不以“系统管理员”显示名称为准 |

权限不足时可能隐藏菜单，也可能请求返回403；不要仅凭按钮出现判断可以操作。账号密码通过独立安全渠道交付，本手册不列出密码。

## 2. 首次使用准备

管理员先完成以下准备，客户再登录：

1. 确认后台和后端可访问。
2. 在“客户资料”创建企业，核对名称、联系人及联系电话。
3. 在企业行的三个点“客户操作”中选择“登录账号”，创建并关联客户账号。
4. 将登录用户名和初始密码安全交付给实际使用人。
5. 超级管理员进入“系统设置 → 小程序功能开关”，按需要开放服务。贸易增量涉及开票和敏感资料提交时，还需开启“敏感资料提交”。
6. 核对“业务模板”的产品记录、模板编号及资料项；没有对应服务或模板时联系维护人员，不让客户盲目重复申请。

开关只决定功能是否开放，不自动完成微信认证、OCR凭据、客服配置、合法域名、业务资质或隐私授权。正式开放前应完成相应核验。

## 3. 一笔报单的最快操作路线

```text
管理员建企业并发放账号
  → 客户登录、选择服务、准备草稿
  → 客户保存资料并提交审核
  → 后台查看原文/附件，逐项审核
      ├─ 有问题：勾选资料、写补充原因、退回通知
      │           → 客户补件重提 → 后台重新审核
      └─ 必填项通过：审核通过，开始办理
                      → 实际办理完成 → 确认办理完成
  → 客户查看已完成状态；授权人员导出资料
```

贯穿双方的核对依据是“报单编号”。企业名称可能重复或有多个月的申请，不能仅凭名称找单。

### 3.1 状态含义

| 状态 | 表示什么 | 下一步由谁处理 |
| --- | --- | --- |
| 草稿 | 已创建，但尚未正式提交审核 | 客户继续填写、保存、提交 |
| 待审核 | 客户已提交或补件重提 | 后台逐项审核 |
| 待补资料 | 后台已要求补充具体资料 | 客户按原因修改并重新提交 |
| 处理中 | 已通过必填资料审核，进入实际办理 | 经办人员完成业务后确认完成 |
| 已完成 | 本报单办理结束 | 客户查看、授权管理员查阅或导出 |
| 已取消 | 该报单已终止 | 只读查看；当前后台未提供通用取消按钮 |

“资料齐全/完成度100%”只表示提交进度，不表示后台审核通过；“已提交”也不表示业务已办理完成。

## 4. 小程序客户操作

### 4.1 登录、微信绑定与切换账号

首次使用：

1. 打开客户端登录页，选择“账号登录”或“首次使用或登录其他账号”。
2. 输入管理员发放的客户用户名、密码。
3. 正式微信环境中，可选择“同时绑定当前微信”；如只想登录另一个账号，不应误勾绑定。
4. 点击“登录账号”，成功后进入首页。

已绑定客户：在微信登录页点击“微信授权登录”，使用此前绑定的账号登录。首次未绑定不会凭微信昵称自动创建业务账号，应先取得客户账号并完成绑定。

本地development可能显示“本地模拟微信登录”，仅用于开发，不证明真实微信授权或绑定已通过。H5不能代替正式微信绑定操作。

切换账号：进入“我的 → 退出登录 / 登录其他账号”，确认“退出并切换账号”后，用另一个账号登录。退出会清除本机企业选择、会话和业务缓存；服务器上已保存的草稿不会因此删除。登录前未保存的输入不要认为已自动保留。微信一键登录仍指向原绑定账号，切换其他账号请走账号登录。已有微信绑定冲突时联系管理员核对，当前不提供自助换绑入口。

### 4.2 首页与“我的”

首页展示当前企业、开放服务及报单入口。“全部服务/查看全部”进入相应列表；没有开放服务时，不应出现可新建的服务。

“我的”包含企业资料、消息通知、退出/切换账号和四类报单统计：全部报单、处理中、待补资料、已完成。点击统计进入二级报单列表，再点具体报单查看资料状态。“我的”页面不再内嵌整张报单列表，报单列表也不是底部Tab页面。

底部导航包含首页、品类匹配、我的；品类入口由开关控制。企业资料为有权访问的脱敏信息，需更正时联系后台管理员。

### 4.3 贸易增量申请

1. 首页进入服务选择，选中“贸易增量”相关产品，按页面选择企业及报单月份。
2. 创建或恢复草稿，进入“资料提交清单”。资料项以该报单实际模板快照为准，不凭旧截图确定必填项。
3. 点开资料项，按类型填写开票信息、文字/链接，或上传附件。
4. 每项填写后执行对应保存操作；文件选择完成后，确认上传成功并出现在附件列表，不能只看见选中文件就认为已保存。
5. 返回清单核对完成度、必填缺失提示和时间说明。
6. 资料不完整时，“继续补充（N）”引导补齐；齐全后点击“提交审核”，等待成功提示。
7. 在“我的 → 全部报单”核对报单编号、待审核状态及最近提交时间。

开票信息包含公司名称、税号、联系地址、联系电话、法人姓名、邮箱、开户行及基本户账号等页面字段，按实际要求填写。敏感字段保存后可能脱敏显示；不要因看不到完整号码重复提交。

模板填写文件：[企业入库信息表.xlsx](./templates/企业入库信息表.xlsx)。需要线下填写时，可由管理员提供此文件，客户填写后按对应附件项上传。当前客户端没有统一“所有模板下载”按钮；不要把企业入库信息表与后台“客户批量导入模板”混用。

### 4.4 附件查看、替换与限制

- 选择前阅读页面给出的格式、单文件大小、数量要求，不同资料项限制可能不同。
- 取消选择不算上传失败，也不应生成空附件。
- 草稿/待补资料且服务允许时，可使用页面提供的上传、删除操作；已提交或服务关闭时按只读提示操作。
- 点击已上传文件查看附件：图片可预览放大，文档按支持的预览/打开方式查看；微信与H5操作表现不同，真机需独立验证。
- 文件链接失效或网络异常时返回报单重新打开，不传播临时预览链接。
- 网银密码、U盾密码、交易密码、验证码不得填写到文字、备注、Excel、附件或任何上传资料中。

### 4.5 草稿与补件

草稿：从报单列表找到草稿，点进去继续编辑。根据页面时间提示区分创建、更新和最近提交，不把草稿创建日期当作今天提交日期。

补件：

1. 进入“消息通知”或“我的 → 待补资料”。
2. 打开对应报单，查看管理员写的具体补充原因及待补资料项。
3. 只针对问题材料补充，其他已通过项不必无故重复上传。
4. 保存、检查清单，再次点击提交审核。
5. 确认状态回到“待审核”，等待后台复核。

若服务开关已关闭，原报单仍可查看，但草稿/补件可能不能修改；此时联系管理员，不重复创建新单规避限制。

### 4.6 商标注册咨询与资质申报服务

服务开放后，选择对应服务进入咨询表单：填写法人姓名、公司名称、联系电话，阅读并勾选页面同意项，可“保存草稿”或“提交咨询”。联系电话已保存时可能只显示脱敏号码；修改时按提示重新输入。

成功后在报单列表查看编号及状态；后台按审核/办理流程跟进。当前是咨询申请与资料流转，不表示已完成商标注册、取得资质或保证审批通过。

### 4.7 品类匹配、通知与客服

品类参考：进入“品类匹配”，手工输入经营范围，例如“软件开发；信息技术咨询；电子产品销售”，提交推荐后查看关键词命中的品类。无命中时调整为营业执照中的实际经营描述，不应把空结果当成异常。

OCR：只有“营业执照图片识别”和“经营范围品类参考”均开启时才具备对应开放条件；上传图片后核对识别文本，有误先修改再匹配。未配置OCR凭据或接口失败时，可手工填写。推荐是关键词参考，不是许可证、保险保单识别或官方经营许可结论。

通知：在“消息通知”查看站内消息、标记已读或进入相关报单；站内通知不等于已实现微信订阅消息推送。

客服：开关开放且微信客服已配置后，在微信小程序点击“联系客服”。H5只会提示在微信中打开；开关开启不等于客服人员、会话或服务时间已配置完成。

## 5. 后台客户资料维护

### 5.1 新增、查看、编辑与删除

1. 登录后台，进入“客户资料”。
2. 新增：点击“新增客户”，填写企业名称、联系电话等必填及需要的选填项，点击“保存客户资料”。
3. 查看：在对应行点击三个点，选择“查看详情”，核对企业编号及脱敏信息。
4. 编辑：选择“编辑资料”，修改后保存。页面提示不回显的敏感字段，编辑时留空表示保留原值，不能把留空理解为删除。
5. 删除：仅超级管理员可使用“删除客户”；确认目标后按确认弹窗操作。此操作为软删除，不等于彻底清除该企业所有历史业务，也没有面向普通用户的恢复按钮。删除前核对关联账号和未完业务，误删交维护人员处理。

### 5.2 发放客户账号与重置密码

1. 企业行三个点 → “登录账号”。
2. 在“创建并关联新账号”填写客户姓名、用户名、手机号、初始密码（至少8位）和企业成员身份。
3. 点击“创建客户账号”，确认新增账号在该企业账号列表出现。
4. 将登录方式和密码单独交付客户，不把密码写到补件通知、备注或导出表。
5. 客户忘记密码时，在该账号旁点“重置密码”，输入新密码并确认，再安全告知客户。

创建客户账号不是创建后台管理员；不要将后台超级管理员密码交给客户。成员身份显示与业务写入权限的具体边界以实际后端校验为准，不仅凭“只读成员”文字承诺所有入口均只读。

## 6. 后台报单审核与办理

### 6.1 找到客户刚提交的报单

1. 进入“报单管理”，清除旧搜索条件，选择“全部状态”或“待审核”。
2. 用客户提供的报单编号或企业名称查询，检查分页。
3. 核对服务类型、月份及最近提交时间；老草稿今天重提仍是原编号，不能只找今天创建的新编号。
4. 点列表的详情入口，进入“资料审核”。

草稿尚未提交时只可查看，不能替客户当作已提交资料审核。时间统一按页面北京时间说明理解，创建时间、更新时间、最近提交时间用途不同。

### 6.2 资料合格：逐项通过，再开始办理

1. 阅读各项原文、开票资料及“查看附件”，核对清晰度、内容及该报单要求。
2. 合格且已提交的资料点击“审核通过”。
3. 检查所有必填资料已通过。“已提交X项”不是“审核通过X项”。
4. 点击右侧“审核通过，开始办理”，确认报单变成“处理中”。
5. 实际业务处理完成后，点击“确认办理完成”，核对“已完成”状态。

“开始办理”或“完成”按钮灰色，优先看左侧是否还有必填项未审核通过；权限不足也会被后端拒绝。不要为了按钮可点而对不合格材料点通过。

### 6.3 有问题：退回选中材料，不是随意改状态

1. 对问题资料勾选“需补充”，可选多项。
2. 填写右侧“补充原因（客户可见）”，说明具体项、问题和修改要求。
3. 点击“退回所选N项并通知客户”，核对数量及原因后确认。
4. 报单进入“待补资料”，通知客户；未选中的其他资料保留。
5. 等待客户补件重提后，重新打开报单审核对应项，再开始或继续办理。

原因示例：“营业执照图片右侧被裁切，请重新上传四角完整、文字清晰的图片。”不要只写“资料有问题”，也不要写密码、个人证件号码或内部敏感信息。

审核与办理是两件事：审核决定材料是否符合要求，办理状态表示实际工作进度。不能用“处理中”跳过必填项审核，也不能把“待补资料”当成办理完成。

### 6.4 线下凭证交接

贸易增量详情中，有对应权限的管理员可看到“线下凭证交接”。分别登记网银凭证、U盾、交易授权凭证的状态：待线下交接、已线下交接、已核验、已归还、无需交接，然后“保存交接状态”。

系统只记录状态、经办人、时间和版本，不保存密码或验证码。真实凭证按企业安全制度线下处理，不通过小程序或附件上传。

## 7. 业务模板、客户导入与资料导出

### 7.1 业务模板

进入“系统设置 → 业务模板”，点击“刷新模板”，选择产品的“查看模板”，核对模板名称、版本、资料数量、必填/选填和敏感标记；下方产品记录用于核对产品编码及状态。

当前此页面主要是查看和核对，不提供完整新增产品、编辑资料项、发布/下架操作表单；这些调整交维护人员按接口与版本规范处理。客户目录会按功能开关过滤，因此空服务目录不一定等于数据库无产品。既有报单使用创建时快照，修改模板不会自动替换历史资料要求。

### 7.2 批量导入客户

1. “客户资料 → 下载导入模板”。
2. 使用这个模板填写，不自行改列名，不混用企业入库资料表。
3. 在“批量导入客户”区域选择文件，等待任务反馈。
4. 根据任务提示核对成功/失败情况；出现错误时按错误反馈修正，不直接反复上传同一文件。
5. 回客户列表搜索导入企业，核对数量和关键字段。无错误报告下载入口时记录任务编号交维护人员查，不把选择文件成功当成导入完成。

导入不等于已发放客户登录账号，仍需按第5.2节关联账号。

### 7.3 导出审核表与资料包

1. 打开目标报单详情，点“导出审核表”；贸易增量报单可按权限点“下载资料ZIP”。
2. 进入“导出中心”查看任务。生成中点击“刷新”，成功后点击“下载”。
3. 资料ZIP按资料目录组织并包含审核表，下载后核对报单编号及材料，不跨客户分发。
4. 下载链接有时效，过期应从任务重新获取，不保存旧链接长期使用。

当前导出记录使用本浏览器会话保存的任务编号回读，换浏览器或清除会话可能看不到原记录，不代表服务器文件已删除。失败或长时间生成中时，记录任务编号和错误交维护人员；权限和文件访问均受后端控制。

## 8. 团队与权限（超级管理员）

1. 进入“系统设置 → 团队与权限”。
2. “新增成员”：填写姓名、用户名、手机号、初始密码（至少12位），选择运营、审核或超级管理员岗位，创建后核对列表。
3. 点击成员的“X项权限”查看其权限清单。
4. 对其他成员点击“调整角色”，选择岗位并保存；后端按新角色校验，必要时重新登录更新菜单。
5. 当前登录账号显示“当前账号”，不能在此界面修改自身角色，以免失去管理权限。

超级管理员具有高影响范围，不应给所有成员。页面未提供完整账号删除、停用和管理员密码重置表单；有此需要联系维护人员，勿把客户密码重置入口误当作后台成员入口。

## 9. 小程序功能开关（超级管理员）

进入“系统设置 → 小程序功能开关”。当前七项均可直接开启/关闭，不需要部署清单、手改数据库或在每次保存后重启服务。

| 开关 | 控制范围/依赖 |
| --- | --- |
| 贸易增量申请 | 新建、保存、提交及补件修改；关闭后既有报单仍可只读查看 |
| 商标注册咨询 | 商标服务入口及咨询申请的写入 |
| 资质申报服务 | 资质服务入口及申请的写入 |
| 经营范围品类参考 | 品类入口与关键词推荐 |
| 营业执照图片识别 | OCR接口开放；还依赖品类参考开启及OCR实际配置 |
| 敏感资料提交 | 敏感附件/文字和开票写入；相应服务也需开启 |
| 微信客服入口 | 微信原生客服入口；另需公众平台配置及实际接待 |

操作步骤：

1. 点击目标开关，阅读影响范围。
2. 填写调整原因，点击“确认保存”，再确认二次提示。
3. 核对配置状态、实际生效及版本增加；不要只看点击动画。
4. 客户重新进入对应页面读取新状态，后端立即按新值校验。

“配置开启”不一定表示依赖满足：OCR在品类关闭时仍未生效；第三方密钥或客服未配置时，开关开启也可能调用失败。

两个管理员同时调整时可能提示版本冲突：刷新配置、核对他人结果后再重新确认，不自动覆盖。请求失败时不应继续盲点。关闭服务会影响正在填写或补件的客户，应提前安排通知和处理方式。

开关不是审核通过证明，不用于审核时隐藏、上线后放开未经核验的业务。本手册不自动替你开启任何功能，当前实际状态以后台回读为准。

## 10. 每日使用检查清单

- 登录后台，核对待审核、待补资料、处理中报单；以详情为准，不只看统计数字。
- 待审核：核对原文附件，处理合格项或写清补件要求。
- 待补资料：跟进客户是否理解原因、能否正常修改和重提。
- 处理中：确认实际业务进度，未完成不提前点“完成”。
- 检查导入/导出失败任务，记录编号与错误。
- 变更开关或权限前检查在办业务影响，变更后重新核对。
- 离开共用电脑退出登录，下载的资料按企业制度保存、分享和清理。

## 11. 常见问题

| 现象 | 先做什么 |
| --- | --- |
| 客户无法登录 | 确认是客户账号、输入无误、账号和企业有效；不要用后台账号登录小程序 |
| 微信提示未绑定 | 先用客户账号密码登录并在正式微信环境绑定；不是输入微信昵称和密码 |
| 微信绑定冲突 | 核对当前微信与客户账号已有绑定，联系管理员，不反复重绑 |
| 连续密码错误后被限流 | 停止重试，等待提示的限制解除或让维护人员排查，不绕过保护 |
| 企业资料空白 | 检查客户账号是否关联正确企业；不直接新建重复企业 |
| 看不到服务或不能上传 | 核对对应服务/敏感资料开关、报单状态及实际权限 |
| 功能开关仍写“部署未允许” | 可能是旧页面/旧后端，刷新后台并让维护人员确认新版服务；当前已取消清单 |
| 后台找不到今天申请 | 获取报单编号；清筛选、检查分页和最近提交时间，确认客户不是仅保存草稿 |
| 资料100%但不能开始办理 | 提交齐全不等于审核通过，检查每个必填项审核状态 |
| 补件按钮不可点 | 至少勾选一个问题项并填写补充原因，确认报单处于可审核状态及有权限 |
| 保存提示版本冲突 | 重新加载最新数据，核对他人的修改，再决定是否提交 |
| 附件打不开 | 返回报单重新获取预览；检查权限、存储服务及手机可访问的文件域名 |
| 小程序点哪里都无响应 | 检查开发者工具“选择页面元素”模式与遮罩；普通编译后再试，记录复现步骤 |
| 两个头部或旧样式 | 确认导入正确development目录，重新编译而非旧build目录 |
| 导出中心无旧记录 | 检查是否换浏览器/会话；任务编号交维护人员查，不判断为数据丢失 |

报错时保留：时间、角色、页面、企业/报单/任务编号、操作步骤、提示及requestId。截图脱敏，不提供密码、Token、身份证/征信原文或银行秘密。

## 12. 本地环境与尚未完成事项

以下供项目维护人员使用，普通客户不需运行命令。命令在项目根目录 `C:\Users\Administrator\Desktop\shopify\wqsf` 的终端执行：

```powershell
docker compose -f infra/docker-compose.yml up -d
docker compose -f infra/docker-compose.yml ps
docker ps --filter "name=wqst-api-dev"
```

已有后端容器需要重新加载已构建JAR时可执行 `docker restart wqst-api-dev`。容器不存在或JAR未构建时，这不是完整安装流程，请按[根目录启动说明](../README.md)处理。不要删除数据库卷、重复执行全部初始化SQL或以重置数据库修复普通报错。

后台、H5、微信watcher各开一个终端，分别运行：

```powershell
pnpm --dir apps/admin-web dev --host 0.0.0.0
```

```powershell
pnpm --dir apps/client-uni dev:h5 --host 0.0.0.0 --port 5175
```

```powershell
pnpm --dir apps/client-uni dev:mp-weixin
```

微信开发者工具导入 `apps/client-uni/dist/dev/mp-weixin`，选择普通编译。本地模拟器联调域名校验等设置由开发者按本地调试要求配置，开发包及本地设置不能作为正式上线包交付。源码改变需重新编译/构建；仅后台开关保存不要求小程序重打包。真机API和文件地址需手机可访问，不能照搬127.0.0.1。

当前边界：正式AppID/微信登录绑定、HTTPS合法域名、腾讯云真实OCR、微信客服实际配置、隐私授权闭环、真机、平台审核和生产验收仍需独立完成。后端具有审计等接口能力，但当前后台不提供独立完整审计查询页、通用取消报单、经办人分配和完整产品发布表单，相关需求交维护人员处理，不在普通日常操作中手改数据库。

本手册为文档和源码核对结果，不表示本轮代替用户点击跑通全部功能。验收用例见[手工测试指南](./08_全流程手工测试指南.md)；开发排查见[后端维护手册](./06_后端维护与Bug定位手册.md)。
