## 文档和代码的关系

- `apps/client-uni`：正式 uni-app 客户端骨架。
- `apps/admin-web`：管理后台骨架。
- `services/api`：Spring Boot 后端实现。
- `apps/design-preview`：高保真设计预览，不作为生产业务代码。
- `database/001_init.sql`：早期 6 张核心表骨架。
- `database/002_full_schema.sql`：本设计对应的完整业务增量结构。
- `database/003_credential_handover.sql`：管理员线下凭证交接状态和权限，不保存认证秘密。
- `database/004_category_match.sql`：营业执照经营范围的品类匹配规则表和 19 条基础规则。
- `docs/templates/企业入库信息表.xlsx`：企业下载填写的开票与基础登记模板，已删除全部密码字段。
- `docs/templates/万企商服通全流程手工测试用例.xlsx`：111 条本地全流程手工用例、合成测试数据、执行总览和缺陷记录模板。
- `docs/changes`：每一次代码、配置、数据库和目录结构变更的说明。
