# 微信小程序备案材料与填写说明

> 编制日期：2026-10-12（2026-10-13 修订，见 [变更记录](./changes/2026-10-13_002_备案服务内容口径修正.md)）
> 适用小程序：万企商服通（AppID `wx4af17ee1c2887e17`）
> 适用主体：衡阳市长全科技有限公司
> 用途：在微信公众平台「设置 → 小程序备案」中逐字段填写时直接对照本文件。

## 1. 这份文件解决什么问题

小程序备案第②步要求填写「备注（必填）」，字数必须为 20–200 字，并且必须具体描述小程序的**实际经营内容**和**主要服务内容**，是主管部门审核的重要依据。写得太空（例如只写“提供企业服务”）会被驳回，写错行业词（例如出现“贷款”“征信”）会触发前置审批要求而直接被退。

因此本文档给出两条可直接复制粘贴的备注文案，并说明同一页其它字段的填写口径。

## 2. 逐字段填写口径

| 字段 | 建议填写 | 说明 |
| --- | --- | --- |
| Appid | `wx4af17ee1c2887e17` | 平台自动带出，只需核对是否为要备案的那个小程序。必须是 18 位，与 `apps/client-uni/src/manifest.json` 的 `mp-weixin.appid` 完全一致。 |
| 小程序名称 | 万企商服通 | 平台自动带出，与已认证名称一致即可。 |
| 服务内容 | 手工选择「生活服务 / 企业管理」，选 1 个即可 | **该字段不会自动带出，必须手动选择**，平台提示“请选择服务内容”。它与微信小程序服务类目不是同一套体系，怎么选见第 2.1 节。 |
| 互联网信息服务前置审批项 | 点「修改信息」，下拉选**「以上都不涉及」**，点「确定」 | 本项目九类前置审批全部不涉及，要在下拉 10 个选项里显式选最后一项。**不要在前 9 类里选任何一项**，会触发许可证要求。详见第 2.2 节。 |
| 备注（必填） | 见第 3 节文案 | 20–200 字。先粘贴再核对字数，系统会实时校验。 |
| 负责人人脸核身 | 由“小程序负责人”本人用微信扫码完成 | 环境要求：浅色或纯色干净背景、无杂物、无他人入镜、不戴帽子/耳机/口罩等遮挡物、不裸露上身、保持表情自然、不闭眼。建议在光线均匀的室内一次做完，避免反复重试。 |

第①步的主体信息必须与营业执照完全一致（名称：衡阳市长全科技有限公司）。第③步上传材料时，证件照片常见退回原因是四角不全、反光、被遮挡或已过期；如需盖章的承诺书，用公司公章。

### 2.1 服务内容怎么选

依据微信官方《服务内容选择指引》和《备案常见问题》：

- 服务内容是**通信管理局的行业分类**，官方原文：“服务内容是通信管局对各个行业的分类，平台部分行业类目与管局行业类目名称不完全一致”。因此它和微信小程序服务类目是两套体系，不要拿小程序类目名称去套，也不要指望平台自动带出。
- 单位主体的红线是活动内容必须与经营范围相符，官方原文：“应选择与主体经营范围、资质相符合的内容”。填之前先打开营业执照核对经营范围。
- 平台提示“建议选1-2个”。**只选 1 个最稳**，多选一项就多一处与经营范围对不上而被退的风险。
- 非政府机关、事业单位不得选择「政务服务」类内容。

本项目建议按下面顺序决定：

| 营业执照经营范围 | 服务内容 |
| --- | --- |
| 含企业管理、企业管理咨询、商务服务、企业服务等表述（即使同时也有软件开发表述） | 生活服务 → **企业管理** |
| 只有软件开发、信息技术服务、技术服务等表述，没有任何企业管理类表述 | 信息传输、软件和信息技术服务业 → **软件开发** |

不要选择「生活服务 → 工具」：本小程序对外表现为企业业务办理工具，但管局分类里的“工具”偏公众效率工具，与营业执照经营范围更难对上。

以下类别本项目一律不选，选中后会直接触发前置审批或被驳回：

| 不要选 | 原因 |
| --- | --- |
| 金融业下任意子项（保险、银行、证券/期货等） | 需要金融主管部门审批文件。本小程序会收集企业征信、网银截图，一旦选了金融类，审核会按金融业务追溯许可证。 |
| 医疗服务 → 医疗器械 / 医药 | 需要《互联网药品信息服务资格证书》。资质申报业务会涉及医疗器械经营许可，但办的是客户的资质，不是小程序自身提供药品信息服务。 |
| 教育 → 培训机构 / 儿童教育 | 需要教育主管部门审批资质。 |
| 休闲娱乐 → 视频、音乐/电台/有声读物、网络图书、网络社交、游戏 | 需要《网络文化经营许可证》或视听节目许可。 |
| 信息传输、软件和信息技术服务业 → 分发平台 | 需要《增值电信业务经营许可证》。 |
| 交通运输 → 打车/出租车 | 需要《网络预约出租汽车经营许可证》。 |
| 政务服务、其他 → 宗教信息 | 主体性质不符。 |

### 2.2 互联网信息服务前置审批项怎么处理

先说结论：**点「修改信息」→ 下拉里选最后一项「以上都不涉及」→ 点「确定」。**

弹窗下拉一共 10 个选项，前 9 个是前置审批类目，第 10 个就是「以上都不涉及」：

```text
新闻 / 出版 / 药品和医疗器械 / 文化 / 广播电影电视节目
网络预约车 / 互联网金融 / 校外培训 / 宗教 / 以上都不涉及
```

这个“以上都不涉及”选项本身就是决定性证据：它是平台专门为“不涉及”的主体准备的答案，说明这一栏是要作答的，只是答案恰好是“没有”。官方 FAQ《备案常见问题》也正是这么说的：

> 2、小程序不涉及前置审批项，如何上传参数？
> 如不涉及前置审批项，也需要填写“以上都不涉及”。

这条问答虽然挂在「服务商相关」章节下（问的是接口参数），但表单下拉用的就是同一套枚举值，所以结论一致：不涉及也要显式选“以上都不涉及”。

《备案指引》里那句“如你的小程序内容涉及前置审批相关信息，请上传有效前置审批文件并填写审批号/文件名”，只是描述**涉及**时的做法，并没有说“不涉及就可以跳过”。把它读成“不涉及就留空”是误读。

**唯一不能做的操作是在前 9 项里随便选一个**，那会直接触发对应许可证要求：

| 选错的后果 | 需要的证件 |
| --- | --- |
| 选了文化、广播电影电视节目 | 《网络文化经营许可证》《信息网络传播视听节目许可证》 |
| 选了药品和医疗器械 | 《互联网药品信息服务资格证书》 |
| 选了互联网金融 | 金融监管部门审批许可文件 |
| 选了新闻 | 《互联网新闻服务许可证》 |
| 选了校外培训 | 教育部门允许开展校外培训的审批文件 |
| 选了出版 | 出版部门材料 / 《网络出版服务许可证》 |
| 选了网络预约车 | 《网络预约出租汽车经营许可证》 |
| 选了宗教 | 《互联网宗教信息服务许可证》 |

九类前置审批类目（本项目全部不涉及）：出版（含游戏、网络出版）、广播电影电视节目（网络视听节目）、药品和医疗器械、文化、新闻、网络预约车、校外培训、宗教、互联网金融。

其中两类容易被误判，说明一下：

- **互联网金融**：本项目是报单与资料提交工具，自身不提供借贷、支付、理财等金融服务；客户上传的企业征信和网银截图是其自身业务材料，不构成互联网金融业务。
- **药品和医疗器械**：资质申报业务里客户可能办医疗器械经营许可，但那是替客户提交申报材料，不是小程序自己提供药品或医疗器械信息服务，不需要《互联网药品信息服务资格证书》。

## 3. 备注文案（可直接复制粘贴）

### 3.1 推荐版本（约 137 字）

```text
本小程序是面向已合作企业客户的企业服务业务办理工具。用户由所属企业管理员开通账号后登录，可在线提交贸易增量材料、知识产权、资质申报三类业务申请，上传营业执照、开票信息等业务资料，查询办理进度、接收补件通知并维护企业资料。资料仅用于该企业自身业务办理，不面向社会公众开放注册。
```

这段文案覆盖了三个审核关注点：服务对象（已合作企业客户，不对外开放注册）、实际经营内容（三类企业服务业务与资料提交）、主要功能（报单、上传、进度查询、通知、企业资料维护）。

### 3.2 精简版本（约 96 字）

适合审核提示“内容过长”或页面字数上限收紧时使用：

```text
本小程序供已合作企业客户办理企业服务业务，支持贸易增量材料、知识产权、资质申报三类业务的在线报单、资料上传、办理进度查询和补件通知查看。账号由企业管理员统一开通，资料仅用于该企业自身业务办理。
```

### 3.3 可按需替换的词

- 三类业务名称与后台种子数据一致：贸易增量、知识产权、资质申报（见 `database/002_full_schema.sql`）。
- 如审核要求写明企业服务范围，可把“企业服务业务办理工具”替换为“企业代办事项的材料提交与进度查询工具”，但不要加入行业资质类表述。

## 4. 措辞红线

以下内容不要出现在备注里，出现后轻则驳回、重则被要求补交对应许可证：

| 类别 | 不要出现的词 | 本项目实际对应情况的正确写法 |
| --- | --- | --- |
| 金融、借贷 | 贷款、融资、放贷、助贷、金融、投资、理财、资金周转 | 小程序会收集法人征信报告、企业征信报告、网银限额与余额截图，但这些只是客户自身业务办理所需上传的资料，备注里统一写“业务资料上传”，不要写成“征信办理”“贷款材料包装”“融资服务”。 |
| 涉税代办 | 代开发票、税务筹划、税收优惠、返税 | 写“开票信息填写”即可，这是客户填写自己公司的开票资料，不是代开发票。 |
| 经营性质 | 平台、商城、交易撮合、招商、加盟、返利、直播 | 本项目不对公众开放注册、不做交易撮合，备注中已用“不面向社会公众开放注册”说明这一点。 |
| 空话 | 提供优质服务、致力于企业发展、打造一流平台 | 平台明确要求具体描述实际经营内容，空话会被驳回。 |

## 5. 审核通过后需要做的事

小程序备案通过后，备案号需要在小程序内可查（通常在首页或“我的”页底部展示）。当前小程序代码中没有任何备案号展示位置（`apps/client-uni/src/pages/` 全部页面均无相关字段），拿到备案号后需要：

1. 在 `apps/client-uni/src/pages/mine/index.vue` 底部或首页页脚新增备案号展示；
2. 同步更新 `docs/03_前端设计与开发规范.md` 和 `docs/changes/`。

## 7. 已知限制

- 本文档的备注文案依据 `docs/00_开发文档总览.md` 的产品范围和 `apps/client-uni/src/pages/` 已实现页面整理，**尚未真实提交通管局审核**，最终口径以平台提示和主管部门要求为准。
- 第 2.1 节的服务内容建议依据官方指引和本项目业务范围推导，但**主体的营业执照经营范围未取得原文核对**（仓库内没有留存主体营业执照），填报前必须用营业执照实际经营范围核对一遍。
- 若审核要求补充说明，可在 20–200 字之间增加功能点，但不要删掉两层意思：服务对象限于已合作企业客户、资料仅用于该企业自身业务办理。这两句是说明小程序不属于公开内容平台的关键。
- 备注中的“贸易增量”是本项目后台种子数据里的业务名称（`database/002_full_schema.sql` 第 365 行），本身不是禁用词，但与该业务配套收集的企业征信、网银截图容易被联想为金融业务。若审核追问，把“贸易增量材料”改成“企业贸易业务材料”即可，其余表述不动。
- 平台下拉选项的名称以微信公众平台当前版本为准；若与本文描述不一致，以平台页面本身为准。
- 第 2.2 节的弹窗下拉内容来自填报人 2026-10-13 的截图（10 个选项，末项为“以上都不涉及”）。平台改版后选项可能变化，以弹窗实际内容为准。
- 前置审批项在网页表单上“不选能否直接下一步”，官方文档没有明文，也没有实测。但既然下拉提供了“以上都不涉及”这个专门答案，选它是在任何解释下都不会出错的选项，因此不必去试留空。
- 本文档关于前置审批项的口径经过两次反复（先是“必须选以上都不涉及”，后改为“保持未填写”，最终回到“选以上都不涉及”）。最终结论的依据是弹窗截图中确实存在该选项，前两次分别是依据不足和过度采信“该问答属于服务商章节”这一条线索。
