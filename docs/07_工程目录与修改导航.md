# 万企商服通工程目录与修改导航

> 目的：让前端开发快速判断某个需求应该修改哪里。  
> 维护规则：新增、删除、移动目录或关键入口文件时必须同步更新本文。

## 2. 管理后台源码目录

```text
apps/admin-web/
├─ .env.development              # 开发环境 API 基础路径
├─ .env.production               # 生产同源 API 基础路径
├─ package.json                  # dev、typecheck、build、check 命令

└─ src/
   ├─ api/
   │  ├─ request.ts              # Token、Request ID、统一错误和 401
   │  ├─ generated-client.ts     # Orval 后台请求适配器
   │  ├─ generated/              # OpenAPI 生成的接口和模型
   │  ├─ auth.ts                 # 登录、当前用户、退出
   │  ├─ dashboard.ts            # 工作台汇总
   │  ├─ unwrap.ts               # 统一拆解 ApiResponse
   │  ├─ cases.ts                # 报单、审核、补件
   │  ├─ companies.ts            # 企业客户分页
   │  ├─ catalog.ts              # 服务目录和资料模板
   │  └─ exports.ts              # Excel/ZIP 导出任务
   ├─ layouts/
   │  └─ AdminLayout.vue         # 后台壳和当前业务页面
   ├─ router/index.ts            # 路由、登录恢复和权限守卫
   ├─ stores/
   │  ├─ index.ts                # Pinia 实例
   │  └─ auth.ts                 # Token、用户、角色和权限状态
   ├─ types/                     # API、认证和工作台 TypeScript 类型
   ├─ views/
   │  ├─ login/index.vue         # 登录页
   │  └─ ForbiddenView.vue       # 403 页面
   ├─ App.vue                    # RouterView 根入口
```

`AdminLayout.vue` 当前承载报单、客户、导出和业务模板页面。上述区域已接入真实接口；后续可按 `views/cases`、`views/companies`、`views/exports`、`views/products` 拆分，继续复用 `src/api/*.ts`，不要直接在页面调用生成目录。

## 5. 需求到修改位置的快速导航

| 需求 | 首先修改 | 通常还要同步 |
| --- | --- | --- |
| 修改后台登录逻辑 | `admin-web/src/api/auth.ts`、`stores/auth.ts` | 登录页、路由守卫、变更记录 |
| 修改 Token 或错误处理 | `admin-web/src/api/request.ts` | 认证 Store、前端规范、登录联调 |
| 修改后台路由或页面权限 | `admin-web/src/router/index.ts` | 侧边栏入口、权限种子、前端规范 |
| 修改工作台统计展示 | `api/dashboard.ts`、`AdminLayout.vue` | 后端 Dashboard 接口、类型定义 |
| 修改接口契约或生成 API | 后端 Controller/record、`config/OpenApiConfig.java` | `pnpm api:sync`、两端 generated 目录、API 文档 |
| 修改小程序文件上传 | `client-uni/src/api/upload.ts` | `FileController`、文件规范、类型检查 |
| 修改后台全局样式 | `admin-web/src/styles.css` | 1440px 和窄屏检查 |
| 前端接口字段变化 | 对应 Controller/Service 的 `record` | API 文档、测试 |
| 新增报单状态 | `CaseStateMachine` | `CaseService`、前端状态文案、总览文档 |
| 修改 11 项资料 | `002_full_schema.sql` 模板种子 | Catalog、前端表单、API 文档 |
| 修改文件格式/大小 | 模板项、`FileInspector` | 上传提示和测试 |
| 修改角色权限 | SQL 权限种子、Controller 注解 | `SecuritySupport`、权限测试 |
| 修改 Excel 导入列 | `ImportService.HEADERS`、`ImportWorker` | 导入模板、错误报告、前端提示 |
| 修改审核 Excel | `ExportWorker.ReviewRow` | API 文档、导出测试 |
| 修改 ZIP 目录 | `ExportWorker.materialZip` | ZIP 安全测试、产品说明 |
| 修改数据库字段 | SQL、Entity、Mapper | Service、数据库文档、集成测试 |
| 修改环境变量 | `application-*.yml`、Compose | README、Review 报告 |
| 修改后台报单交互 | `admin-web/src/api/cases.ts`、`AdminLayout.vue` | `AdminCaseController`、状态机、权限 |
| 修改后台客户导入 | `admin-web/src/api/companies.ts`、`AdminLayout.vue` | `ImportController`、导入模板 |
| 修改后台产品资料模板 | `admin-web/src/api/catalog.ts`、`AdminLayout.vue` | `CatalogController`、模板种子 |
| 修改后台导出 | `admin-web/src/api/exports.ts`、`AdminLayout.vue` | `ExportController`、SeaweedFS、下载审计 |

## 6. 不要直接修改的目录

- `services/api/target/`：Maven 构建产物，重新构建会覆盖。
- `apps/*/dist/`：前端构建产物，应该修改源码后重新构建。
- 已经上传到 SeaweedFS 的对象路径：应通过后端服务操作。
- 已有 Docker Volume：未确认内容前不能删除或重建。
