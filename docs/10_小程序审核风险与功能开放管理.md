## 2. 规则依据与边界

- [个人信息保护法（网信办）](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)：必要性、敏感信息保护与单独同意等义务。
- [微信隐私适配说明（腾讯官方文档）](https://cloud.tencent.cn/document/product/1301/97930)：隐私指引与相应接口授权要求；其中微搭自动适配能力不能推定本项目也具备。
- [商标代理监督管理规定（国家知识产权局）](https://www.cnipa.gov.cn/art/2024/1/30/art_3323_190078.html)：实际代理业务的备案核验依据；微信具体类目以公众平台当前要求为准。
- [微信平台运营规范入口](https://developers.weixin.qq.com/miniprogram/product/) 与 [服务类目入口](https://developers.weixin.qq.com/miniprogram/product/material/)：本轮网页读取失败，不能宣称已全文核对现行条款；需由账号管理员核对当前平台页面。

备案行业分类、平台服务类目、代码审核和业务经营资质是不同核验事项。不得仅修改名称来避开资质，或审核时隐藏、上线后放开未审核业务；布尔值不是“过审认证”。

## 3. 功能开关设计与当前值

匿名 `GET /api/v1/client/capabilities` 返回统一 ApiResponse，data 是七个布尔字段。有效值 = 数据库 enabled；OCR 还依赖品类匹配开启。超级管理员直接控制所有七项。

| 字段 | 新库/当前本地默认有效值 |
| --- | --- |
| tradeApplicationEnabled | false |
| trademarkConsultationEnabled | false |
| qualificationConsultationEnabled | false |
| categoryMatchEnabled | true（仅手填关键词参考） |
| licenseOcrEnabled | false |
| sensitiveMaterialUploadEnabled | false |
| customerServiceEnabled | false |

2026-10-14 经用户确认取消部署开放清单：`CLIENT_CAPABILITY_RELEASE_ALLOWED` 和 `wqst.capabilities.release-allowed` 不再读取，旧环境变量即使存在也不影响功能。超级管理员通过后台即可调整，不需改数据库或重启。正常使用开关仍需先核实资质、隐私和所需审核；系统不会自动核验这些条件，也不会按审核员身份或版本开放。

## 4. 管理员配置接口

- `GET /api/v1/admin/client-capabilities`：后台登录且角色 `SUPER_ADMIN`，返回 key/enabled/version/releaseAllowed。
- `PUT /api/v1/admin/client-capabilities/{key}`：后台登录且角色 `SUPER_ADMIN`；请求 `{"enabled":false,"version":0,"reason":"维护原因"}`。普通管理员即使有产品编辑权限也返回403。
- 七项均可直接开启/关闭，不再返回FEATURE_RELEASE_NOT_ALLOWED；过期版本 409 OPTIMISTIC_LOCK_CONFLICT；未知 key 404 CAPABILITY_NOT_FOUND。releaseAllowed响应字段为兼容旧客户端保留且固定true，不表示合规核验结论。
- 修改与 CAPABILITY_UPDATE 审计在同一事务内，无公开修改入口。
- 后台入口：系统设置 → 小程序功能开关（`/capabilities`），仅超级管理员显示。页面展示七项开关与实际生效状态；填写原因并二次确认后保存，版本冲突要求重新确认。正常操作无需手改数据库或部署变量。此次没有改变当前功能值，业务是否开放由超级管理员手动决定。

## 5. 客户端与后端执行范围

目录只返回有效开启的服务；新申请、简表/开票/文字保存、报单提交、附件上传都在后端校验。敏感资料上传/文字及开票需额外敏感开关。绕过页面直接请求仍会返回 403 FEATURE_DISABLED。

已有报单列表/详情、时间线、模板和已授权附件预览继续提供。关闭服务时已有草稿/补件变成只读；因此关闭操作会影响正在补件的客户，管理员需提前安排服务与通知。仅关闭敏感收集不禁止已收齐资料的报单提交。删除草稿附件沿用原权限允许，避免阻碍用户移除已有数据；这不是完整的已提交资料删除申请流程。

小程序获取配置失败时将全部能力置 false，不缓存开放值到本地存储；旧资料查询仍保留。服务页/草稿编辑、图片识别、品类底栏和客服入口同步控制。已经打开的页面在下一次读取配置前可能有旧按钮，后端以实时值为准并拒绝操作。关闭功能不是将未审核页面永久移除代码包；提审范围还需平台核实。

## 6. 手工验收

1. 不登录读取 capabilities，确认字段是布尔值且没有密钥或客户数据。
2. 当前默认目录为空；直接创建报单返回 FEATURE_DISABLED，而非只隐藏按钮。
3. 登录客户，打开已有报单和图片应仍可查看，关闭服务的草稿不可编辑。
4. 客户/未登录访问管理修改接口不能成功；普通管理员无菜单、直接访问路由进入403页、配置查询/修改接口均403。超级管理员在独立测试环境关闭 categoryMatchEnabled 并填写原因后，推荐接口返回 403。
5. 重用旧 version 修改应 409；审计可查到正确管理员和原因。
6. 独立测试环境中超级管理员逐个开启/关闭七项应成功，检查版本增加、审计及匿名实际值；无需部署清单。恢复原值，普通管理员仍不能调整。
7. 断开 API 后再次读取配置，入口关闭但给出重试提示；不保留上次 true。
8. 正式上线前单独做微信隐私、真实登录、合法域名、原生客服和真机文件测试。
