## 4. 真实数据规则

- 前端不再写入报单、公司、模板或导出记录的固定演示数组。
- 手机号、统一社会信用代码、税号、银行账号等只显示后端脱敏字段。
- 导出任务 ID 只在当前浏览器 `sessionStorage` 保存，用于刷新后查询本人创建的任务；服务端仍执行归属校验。
- Excel 导出和 ZIP 导出分开使用权限；ZIP 只对贸易增量报单显示。
- 报单资料审核必须携带后端返回的乐观锁版本号。

## 7. 已知限制

- 后端暂未提供导出任务分页历史接口，导出中心仅展示当前浏览器记录过的任务；跨设备历史需要新增 `GET /api/v1/admin/exports`。
- 后台业务仍集中在 `AdminLayout.vue`，后续可按 `views/cases`、`views/companies`、`views/exports`、`views/products` 拆分，拆分时保持领域 API 文件不变。
- 本地数据库没有强行写入假报单。没有报单时页面展示真实空数据状态；完整审核闭环应通过客户端接口创建脱敏测试报单。
