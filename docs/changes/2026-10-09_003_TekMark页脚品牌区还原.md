# TekMark 页脚品牌区还原

> 日期：2026-10-09  
> 序号：003  
> 类型：修复 / 前端静态页面  
> 状态：已完成

## 1. 为什么要修改

TekMark 名片页的页脚品牌简介区与参考图不一致：`TekMark Card` 没有显示蓝色品牌字，说明文字和 Shop cards 按钮依赖负外边距摆放，容易发生错位或重叠。

## 2. 修改文件清单

| 文件 | 类型 | 修改内容 |
| --- | --- | --- |
| `tekmark-card.html` | 修改 | 将页脚品牌区改为两列布局，恢复蓝色 `Mark`，移除按钮负外边距 |
| `docs/03_前端设计与开发规范.md` | 修改 | 补充页脚品牌区布局和颜色规则 |
| `docs/changes/README.md` | 修改 | 登记本次变更记录 |

## 3. 修改前后的逻辑

### 修改前

- 标题 `TekMark Card` 全部为白色。
- 说明文字最大宽度固定为 302px。
- Shop cards 按钮使用 `margin-top: -36px` 向上叠放。

### 修改后

- 标题拆分为 `Tek`、蓝色 `Mark` 和 `Card`，与参考图一致。
- 品牌文案与按钮使用 CSS Grid 两列排列。
- 左侧文字自动占据剩余空间，右侧按钮保持固定列宽。
- 按钮不再通过负外边距定位，避免邮件画布宽度变化时发生遮挡。

## 4. 接口、数据库和前端影响

- 接口：无新增、无修改。
- 数据库：无新增、无修改。
- 前端：仅影响根目录 `tekmark-card.html` 页脚品牌简介区域，不改变外链和正式业务应用。
- 配置：无变化。

## 5. 目录结构变化

无新增、删除或移动目录和关键文件。

## 6. 验证结果

- 静态检查：标题品牌色、两列结构和按钮样式已写入，旧的 `margin-top: -36px` 已移除。
- 浏览器本地渲染：Chrome Headless 成功生成 375px 视口截图，品牌文案和按钮已分列，`Mark` 显示为蓝色。
- 未执行单元测试、集成测试、容器实跑或生产验证。

## 7. Bug 定位和回退

- 文案或按钮错位：优先检查 `.footer-intro` 的网格列、间距和 `.footer-shop-button` 宽度。
- 品牌色异常：检查 `.footer-intro h3 span` 和 `--blue` 变量。
- 回退方式：恢复原来的标题文本与按钮外边距样式；不涉及接口和数据库回滚。
