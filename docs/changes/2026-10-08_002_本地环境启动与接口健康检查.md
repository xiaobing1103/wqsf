## 7. Bug 定位和回退

- 容器异常时先执行 `docker compose -f infra/docker-compose.yml ps` 和 `docker compose -f infra/docker-compose.yml logs --tail 100`。
- 后端无法连接 MySQL 时先检查 3306 端口、`wqst-mysql` 健康状态和 `application.yml` 默认连接参数。
- 后端出现 `Unable to establish loopback connection` 时，先确认 `C:\Windows\Temp` 存在，再为当次 Java 进程设置 `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\Windows\Temp`。
- 后台页面可打开但请求失败时，检查 8080 后端、`apps/admin-web/vite.config.ts` 的 `/api` 代理和浏览器 Network 请求。
- 停止时在后端和后台终端分别按 `Ctrl+C`，再执行 `docker compose -f infra/docker-compose.yml down`。不使用 `down -v`，避免删除本地数据卷。

## 8. 已知限制

- 本地管理员会保留在 `wqsf_mysql_data` 数据卷中；重启后端时 Bootstrap 不会重置已有账号的密码。
- 未验证小程序、正式微信登录、HBuilderX/DCloud 编译、真机或生产环境。
