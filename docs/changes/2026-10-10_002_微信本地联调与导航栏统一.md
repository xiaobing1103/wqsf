# 微信本地联调与导航栏统一

> 日期：2026-10-10  
> 序号：002  
> 类型：修复 / 配置 / 文档  
> 状态：已完成（微信开发者工具模拟器已验证，真机和生产待验证）

## 1. 为什么修改

微信小程序目标包原来默认走正式微信登录，但本地尚未配置可用的 AppSecret，导致开发者工具无法建立客户会话并请求本机后端。页面同时启用了 `navigationStyle: custom` 并渲染自定义 `AppHeader`，与微信开发者工具显示的系统导航区域叠加，造成头部重复。

本次目标是在不改变正式登录路径的前提下，让开发构建可以连接本机 `127.0.0.1:8080`，并让全部八个业务页面统一使用微信原生导航栏。

## 3. 修改前后的逻辑

### 修改前

```text
微信开发构建 -> uni.login -> /auth/wechat/login
                -> 本地无正式微信凭据，无法建立客户会话

页面 -> 微信系统顶部区域 + 自定义 AppHeader
       -> 标题和返回区域重复
```

生成的 Orval 代码还直接引用浏览器全局对象 `Headers` 和 `URLSearchParams`，在微信逻辑层会分别出现未定义错误。

### 修改后

```text
development 构建
  -> VITE_CLIENT_AUTH_MODE=dev
  -> /api/v1/auth/client/dev-login
  -> Token -> 本地业务接口

非 development 微信构建
  -> uni.login
  -> /api/v1/auth/wechat/login

全部页面
  -> pages.json 原生导航栏
  -> 页面正文（不再渲染 AppHeader）
```

`pnpm api:generate` 会在 Orval 生成后自动执行兼容补丁：请求头按可迭代对象处理，查询参数通过 `encodeURIComponent` 生成，不再依赖微信运行时缺失的浏览器全局对象。

## 4. 接口、数据库和前端影响

- 接口：路径、请求、响应和错误码均无变化；只在开发构建选择既有 `/api/v1/auth/client/dev-login`。
- 数据库：表、字段、索引和种子数据均无变化。模拟器验收时新增了一笔明确标记为本地合成数据的商标咨询草稿，不属于结构或种子变更。

- 配置：新增 `VITE_CLIENT_AUTH_MODE=dev`。该文件只由 development 模式读取，正式构建不会自动启用开发登录。

## 7. Bug 定位和回退

- 无法连接接口：先检查 `docker compose -f infra/docker-compose.yml ps`、Actuator Health、后端是否使用 `local` Profile，以及微信开发者工具导入的是否为 `dist/dev/mp-weixin`。
- 返回 401：检查 `.env.development`、`stores/auth.ts`、本地配置的 `wqst.auth.dev-client-login-enabled` 和缓存的 `wqst_client_token`。
- 开发者工具重新编译后仍提示“微信登录尚未配置”：先确认项目路径是 `dist/dev/mp-weixin` 而不是 `dist/build/mp-weixin`，关闭旧项目窗口并在开发项目中手动清除编译缓存后重编。当前工具的 CLI 服务端口未开启，不能依赖命令行自动重开项目，也不需要为本地接口联调修改安全设置。
- 出现 `Headers is not defined` 或 `URLSearchParams is not defined`：重新执行根目录 `pnpm api:generate`，并检查 `scripts/patch-uni-generated.mjs` 是否成功报告替换数量。
- 标题重复：检查 `pages.json` 是否又加入 `navigationStyle: custom`，或页面是否重新引入 `AppHeader`。
- 回退：恢复 `pages.json` 和八个页面、恢复 `AppHeader.vue`、移除开发环境文件与生成兼容脚本，并恢复根目录 `api:generate` 命令；不需要回滚数据库。

## 8. 已知限制

- 电脑模拟器中的 `127.0.0.1` 指向开发电脑；真机中的 `127.0.0.1` 指向手机自身。真机本地调试必须改用电脑局域网 IP，并放行防火墙端口。
- 正式发布必须使用 HTTPS 合法域名，并完成正式 AppID/AppSecret 登录、公众平台域名配置和真机验收。
- 微信原生客服仍依赖公众平台客服人员配置。
- 报单时间线仍未接入小程序。
