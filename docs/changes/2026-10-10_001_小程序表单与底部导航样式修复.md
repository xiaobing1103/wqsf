# 小程序表单与底部导航样式修复

> 日期：2026-10-10  
> 序号：001  
> 类型：修复 / 样式 / 文档  
> 状态：已完成

## 1. 为什么修改

小程序资质/商标咨询简表的输入框使用 `width: 100%` 时仍按 `content-box` 计算，左右内边距会叠加到宽度之外，导致输入框越过表单卡片右边界。首页“全部服务”和“查看全部”按钮没有实体边框，并使用负右边距，视觉上出现右侧边框缺失。底部导航仅有顶部细线和三列文字图标，选中反馈较弱，整体层次不清晰。

## 3. 修改前后的逻辑

### 修改前

- `uni-input` 外层为 `content-box`，`width: 100%` 之外继续叠加左右 padding，超出父级字段和表单卡片。
- 首页文字按钮为透明背景、无边框，并通过负右边距靠近页面边缘，右侧可点击区域和视觉边界不完整。
- TabBar 三个按钮直接平铺，仅改变激活文字颜色，没有明确的选中容器和层次。

### 修改后

```text
简表字段 -> border-box 输入框 -> 始终限制在字段宽度内
首页标题区 -> 有边框文字按钮 -> 保持在页面左右安全边距内
页面底部 -> 半透明导航容器 -> 选中图标胶囊 + 文字状态
```

- 输入框的边框、padding 和内容共同包含在 `100%` 宽度内。
- 两个首页操作按钮使用完整浅色边框、白色背景、圆角和轻阴影，按压时显示浅绿色反馈。
- TabBar 保留原导航逻辑，增加顶部阴影、半透明背景、统一留白、圆角按压态和浅绿色选中胶囊。

## 7. Bug 定位和回退

- 输入框再次溢出时先检查 `service/simple.vue` 的 `.field input` 是否仍为 `box-sizing: border-box`，再测量 `uni-input` 外框与 `.form-card` 右边界。
- 首页按钮边框异常时检查 `.text-action` 的 `border`、`margin` 和父级 `.section-heading` 的左右 padding。
- TabBar 遮挡内容时检查 `BottomNav.vue` 高度和 `App.vue` 的 `.safe-page` 底部留白是否匹配。
- 回退只需恢复上述三个 Vue 文件；不涉及接口、数据库、依赖或数据回滚。
