# 后台最近报单布局优化

> 日期：2026-10-14
> 序号：002
> 类型：修复 / 前端样式
> 状态：代码与构建检查完成，浏览器视觉待用户复验

## 1. 为什么修改

工作台“最近报单”的 recent-case 系列节点缺少对应布局样式，导致企业标识、名称、编号、服务类型、状态和时间堆在左侧。英文服务编码不便阅读，时间也没有说明含义。

## 2. 修改文件清单

| 文件 | 类型 | 修改内容 |
| --- | --- | --- |
| `apps/admin-web/src/layouts/AdminLayout.vue` | 修改 | 分离企业名称、编号与服务标签；服务编码转中文；最近提交/草稿创建时间；查看全部使用现有箭头图标 |
| `apps/admin-web/src/styles.css` | 修改 | 网格行布局、独立企业标识、分隔线、悬停背景、长名省略、900/560px 换行规则 |
| `docs/03_前端设计与开发规范.md`、`docs/05_后端实现与Review报告.md`、`docs/changes/README.md` | 修改 | 展示规范、验证边界和索引 |

## 3. 修改前后的逻辑

修改前：缺少行布局，信息连续堆叠，显示原始服务编码，时间取最近更新但不说明含义。

修改后：每条报单独立一行，左侧企业标识，中间名称、编号和中文服务，右侧状态与时间。长名省略且鼠标悬停可查看全名。已提交显示 submittedAt 并标明“最近提交”；无提交时间显示 createdAt 并标明“草稿创建”。窄屏状态和时间换行，保留原有“查看全部”导航。

## 4. 接口、数据库和前端影响

- 接口、数据库、配置：无变化，复用现有摘要字段，不调整排序或权限。
- 前端：仅工作台最近报单展示，不改变报单审核、状态流转和小程序。

## 5. 目录结构变化

无业务目录或关键入口变化，仅新增本变更记录。

- `pnpm --dir apps/admin-web check`：Vue TypeScript 静态检查及 Vite 生产构建通过。
- `git diff --check`：通过（仅 Git 换行符提示）。
- 本轮未执行浏览器桌面/窄屏视觉验收、单元测试、后端集成测试、容器业务闭环或生产验证；上一轮验证不计为本轮通过。

## 7. Bug 定位和回退

显示问题先检查 styles.css 的 recent-case 系列和 AdminLayout.vue 最近报单节点；时间字段查看接口摘要的 submittedAt/createdAt。回退仅恢复本轮对应节点、serviceText 函数和新增样式，不覆盖上一轮审核整改，也无需数据库回退。

## 8. 已知限制

本轮没有浏览器截图验收。未知服务编码保留原值，不擅自映射；单条记录未新增点击行为，仅沿用查看全部入口。企业全名悬停提示用于桌面鼠标，触屏以报单列表/详情为准。
