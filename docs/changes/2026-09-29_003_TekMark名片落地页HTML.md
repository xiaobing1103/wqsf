根据 TekMark 名片设计稿交付一个可直接打开的 HTML 文档。现有 `img/` 目录只提供了 Logo 和卡片堆叠图，设计稿中的商务背景图与联系人头像缺失，因此页面保留了尺寸、圆角和层级一致的占位区域，方便后续补图。

## 3. 修改前后的逻辑

### 修改前

项目中没有该设计稿对应的独立 HTML 页面，无法直接预览 TekMark 名片分享流程。

### 修改后

浏览器直接打开 `tekmark-card.html` 即可查看完整页面：

```text
Header.png → 联系人介绍与资料卡 → Frame 2.png → 行动号召 → logocom.png 页脚
                         ↘ 缺失背景图、头像保留同尺寸占位
```

页面使用 CSS 完成布局、字体、颜色、间距、圆角和移动端适配；按钮与页脚链接使用锚点作为静态演示，不调用后端接口。

## 7. Bug 定位和回退

- 页面显示异常：先检查 `tekmark-card.html` 的 CSS 与浏览器控制台，再确认 `img/` 下三个文件名（特别是 `Frame 2.png` 的空格）。
- 图片未显示：先检查相对路径和文件大小；缺失的背景图、头像对应 `.hero-placeholder` 和 `.avatar-placeholder`。
- 回退方式：删除 `tekmark-card.html`，并回退本记录中对 03、07 文档及变更索引的登记即可，不涉及业务代码或数据库回滚。
