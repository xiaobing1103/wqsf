# 小程序双登录与账号切换

> 日期：2026-10-10  
> 序号：004  
> 类型：功能 / 安全 / 前后端联调 / 文档  
> 状态：已完成本地验证，待正式微信与生产验证

## 1. 为什么修改

原小程序只有 development 模拟登录或正式微信入口，客户看不到清晰的账号密码登录、首次微信绑定、退出和登录其他账号流程。正式微信适配器也只保留了接口边界，未实际调用微信服务。管理员缺少按企业发放客户账号和重置密码的入口。

本次目标是兼容两种方式：客户可以直接使用管理员发放的账号密码登录；在正式微信中首次密码登录时可绑定当前微信，后续一键登录。用户还能安全退出并切换账号，切换后不能继承上一账号的企业、草稿或幂等缓存。

## 3. 修改前后的逻辑

### 修改前

- development 包用 `/auth/client/dev-login` 自动进入业务页，客户没有显式双登录页。
- 正式微信接口没有实际换取 OpenID，无法完成真实绑定。
- 用户退出和登录其他账号的入口、业务缓存隔离不完整。
- 管理后台不能在企业客户列表中发放或重置 CLIENT 账号。

### 修改后

```text
小程序启动
  -> 有 Token：/auth/me 恢复会话
  -> 无 Token：进入双登录页
       -> 微信登录
            -> development：模拟已绑定微信登录
            -> 正式微信：uni.login -> jscode2session -> 已绑定账号登录
       -> 账号密码登录
            -> 普通登录
            -> 正式微信可勾选绑定 -> 新 code + 密码校验 -> 绑定并登录

管理员 -> 客户列表三点菜单 -> 登录账号
  -> 查看已关联账号 / 创建 CLIENT 账号 / 选择成员身份 / 重置密码

退出或 401 -> 服务端注销（可用时）-> 清 Token 和业务缓存 -> 登录页
```

正式微信未绑定时返回明确错误，要求先使用管理员发放的账号密码登录并绑定；系统不会自动生成没有企业关系的空账号，也不会静默覆盖现有绑定。

## 4. 接口、数据库和前端影响

- 接口：新增 `POST /api/v1/auth/client/login`、企业客户账号查询/创建/重置接口和通用密码重置接口；`POST /api/v1/auth/wechat/login` 从占位边界升级为真实微信 code 换取实现。
- 数据库：无结构、索引和种子数据变化。复用 `user_account.username`、`password_hash`、`wechat_openid`、`wechat_unionid`、`last_login_at` 及 `company_user`。
- 前端：新增小程序登录页；认证 Store 只恢复已有 Token，不自动弹起微信授权；“我的”新增退出/切换账号；后台客户操作菜单新增登录账号维护弹窗。
- 配置：正式微信仍使用既有 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`。本地 development 不保存任何真实微信密钥。
- 安全：密码仅存 BCrypt 哈希；微信 `session_key` 不保存、不返回；管理员和客户登录失败计数隔离；绑定冲突拒绝覆盖；账号创建和重置写审计。

## 7. Bug 定位和回退

- 客户密码登录：先查 `AuthController.clientLogin`、`AuthService.clientLogin`、`UserAccountMapper`、`user_account` 状态及 Valkey 的 `wqst:auth:fail:client:*`。
- 微信登录/绑定：按 `WECHAT_AUTH_NOT_CONFIGURED`、`WECHAT_CODE_INVALID`、`WECHAT_AUTH_UNAVAILABLE`、`WECHAT_ACCOUNT_UNBOUND`、`WECHAT_ALREADY_BOUND`、`ACCOUNT_WECHAT_ALREADY_BOUND` 分类，再查 `WechatAuthClient` 和 OpenID 绑定字段。
- 小程序：检查 `pages/auth/login.vue`、`stores/auth.ts`、`api/auth.ts`、`generated-client.ts` 和当前构建是否为 `dist/dev/mp-weixin`。
- 后台发放账号：检查 `api/companies.ts`、`AdminLayout.vue`、`AdminCompanyController`、企业成员关系和操作日志。
- 回退需同时恢复认证、账号、企业 Controller/Service、后台弹窗、小程序登录页与 Store，并重新执行 `pnpm api:sync`；本轮无数据库迁移，不需要数据库结构回滚。

## 8. 已知限制

- 本地 development 的“微信登录”是合成账号模拟，只验证本机流程，不代表微信服务通过。
- 正式微信登录、首次绑定和换取 OpenID 需要有效 AppID/AppSecret、公众平台配置和真机；本轮没有这些条件，因此未执行。
- 当前不提供客户自助找回密码或自行解除微信绑定；需由管理员重置密码，换绑需后续设计带审计的安全流程。
- 管理后台团队页暂未暴露管理员密码重置和账号停用交互，后端通用重置接口仅作为超级管理员能力保留。
