# TekMark 移除背景图区

> 日期：2026-10-21  
> 序号：003  
> 类型：界面调整

## 1. 为什么修改

用户反馈 Gmail 中头像没有与背景叠放，随后明确要求去掉背景图。按最新要求移除整个背景区域，避免残留大块深色占位。

## 3. 修改前后的逻辑

### 修改前

名片顶部为 16:10 背景区，头像依赖叠放结构跨在背景底边。用户提供的 Gmail DOM 中负边距及背景图片地址丢失；收到最新指令前正在本地调整叠放结构，尚未完成真实邮箱验证。

### 修改后

移除背景区、深色占位、比例占位层、叠放表格及相关 MSO 样式。头像放在资料卡顶部正常表格行，顶部间距 24px，姓名、职位、资料按钮和下载链接依次排列。保留其他区域及文案。

头像由 CSS 背景改为常规动态 img，保持圆形蓝边与 94px 外框，避免只保留背景底色却没有图片标签。删除不再使用的 owner.background_url，其余六个字段和个人链接保留。

## 4. 接口、数据库和前端影响

- 接口、数据库、配置：无变化。
- 前端：仅独立邮件 HTML 更新，不涉及业务应用路由与状态。
- 发信接入：模板不再读取 background_url；必须填入真实 avatar_url。头像为空时，发送端应省略 img 并保留底色单元格，不能发送未替换的变量。

## 5. 目录结构变化

无业务目录及关键入口变化，仅新增常规变更记录。

## 6. 验证结果

- 静态检查：背景相关结构、background_url 字段及头像负边距已移除，HTML 表格标签配对；剩余六个动态字段与三个跳转链接保留，git diff --check 通过。
- 本地 Chrome：320、375、517、900px 四种视口均无横向溢出，头像外框均为 94px；查看 517px 截图确认顶部背景区已移除。
- 本地模板尚未填入 avatar_url，真实头像未加载；不能将其记为真实头像或 Gmail 验证通过。
- 未执行单元测试、集成测试、容器实跑、真实邮件发送或生产验证。

## 7. Bug 定位和回退

- 仍显示背景：检查发送端是否仍使用旧版模板或缓存内容。
- 头像不显示：检查最终 HTML 中 img 的 src 是否为公开图片 URL，而非空值、未替换变量或需要登录的地址。
- 回退：恢复原背景区、比例样式与头像叠放结构，并同步恢复规范说明；不涉及数据库回滚。

## 8. 已知限制

未验证真实 Gmail 发信链路，不能承诺发送平台保留全部样式。未渲染动态字段的本地预览可能出现头像缺图标记。顶部 Logo 仍使用旧裁切方式，本次未调整。
