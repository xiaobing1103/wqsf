## 3. 修改前后的逻辑

### 修改前

白色背景、最大 600px 主体；顶部整张标题图加 `Keep the conversation going-` 标题；头像在封面后另起一行；推广按钮无箭头；页脚包含品牌介绍、商品与支持导航、社交入口及偏好设置。

### 修改后

浅蓝背景、最大 470px 白色圆角主体；顶部仅展示品牌 Logo，主标题改为 `FIRST IMPRESSIONS, SOLVED`。资料卡封面底边叠放 94px 圆形头像，姓名、职位、资料按钮及下载链接分别排列。推广区和地址页脚按设计稿缩减。所有固定英文文案、箭头、介绍中的直引号及地址 `PO BOX 99900` 均按新稿更新。

保留七个 `owner.*` 动态变量及原有资料页、vCard、官网购买链接。封面与头像为空时仍显示纯色占位，不引入固定样例人物。顶部 Logo 从已有图片中用 CSS 裁切展示，页脚继续使用已有品牌图片。新增 Poppins 网络字体与手机媒体查询，并保留邮件表格、行内样式、按钮 `bgcolor` 和 MSO 回退。

## 6. 验证结果

- 静态检查：核对七个动态字段、主标题、介绍、两个按钮与下载链接文字、地址及旧模块移除，检查通过。
- HTML 结构：通过脚本检查展示表格和链接标签配对，模拟七个变量替换后无残留占位符。
- 浏览器：本地 Chrome Headless 使用 CDP 设置真实 320、375、517、900px 视口并截图；四种宽度的 `scrollWidth` 均等于视口宽度，两个 Logo 均成功加载，Poppins 字体加载成功。
- 视觉检查：查看 517px 与 320px 截图，头像跨在封面底边、姓名未被遮挡、按钮背景可见；窄屏允许介绍、推广标题与地址自然换行。
- 本轮未执行单元测试、集成测试、容器实跑、真实邮箱发信或生产验证；此修改不涉及业务接口和容器服务。

## 7. Bug 定位和回退

- 仍显示旧文案：先确认发送端或浏览器使用的是本次更新后的完整 `tekmark-card.html`，并检查缓存。
- 无联系人图片：检查发信端是否提供公开可访问的 `owner.background_url` 和 `owner.avatar_url`，缺图时显示纯色属于既有行为。
- 邮箱字体、Logo 或头像位置不同：检查邮件平台是否清理网络字体、裁切和负边距样式；经典 Outlook 使用系统字体及头像边距回退。
- 回退：恢复改动前的 HTML 与对应规范段落；改动前 HTML 另存于本机临时目录 `tekmark-design-check/tekmark-card-before.html`，无需数据库或服务回滚。

## 8. 已知限制

设计稿中的人物照片和封面原图未提供独立资源，继续通过动态字段填入；浏览器默认预览为纯色占位。网络字体、CSS 裁切、圆角及背景图片在不同邮箱中的支持程度不同，真实邮箱尚未验证。资料页与 vCard 链接仍需发信系统填充，未对未渲染的变量链接执行跳转。
