# TekMark 缺图纯色占位

> 日期：2026-10-13
> 序号：005
> 类型：修复 / 邮件 HTML
> 状态：本地检查通过，待真实发信复验

## 1. 为什么修改

用户反馈没有头像时邮件中出现裂图。截图中的裂图图标位于资料卡横幅左上角，说明横幅图片缺失时也有相同问题。原模板把两处动态图片直接放入 `<img src>`；空地址或无法访问的地址会由邮件客户端显示裂图图标，纯色背景无法覆盖这个图标。

## 3. 修改前后的逻辑

### 修改前

横幅和头像均为 `<img src="{{ owner.xxx }}">`。缺图时可出现裂图图标。

### 修改后

横幅始终有深蓝底、头像始终有灰蓝底和蓝色边框。有有效图片 URL 时背景图覆盖底色；当字段替换为空字符串或图片加载失败时，只显示纯色底，不出现 `<img>` 裂图图标。姓名仍位于头像下一行，不会被遮住。七个 `{{ owner.xxx }}` 字段名称未改变。

## 4. 接口、数据库和前端影响

- 接口：无变化。发信端必须把缺失的 `owner.background_url`、`owner.avatar_url` 替换为空字符串，不应保留原占位符。
- 数据库：无变化。
- 前端：仅独立邮件 HTML 的两处动态图片展示方式变化；业务应用页面、路由和状态管理不变。
- 配置：无变化；线上独立模板需重新上传。

## 5. 目录结构变化

无代码目录或关键入口变化；仅新增本变更记录。

## 6. 验证结果

- 静态检查：横幅和头像已无动态 `<img>`，两处均保留纯色底；分别用空字符串和示例 URL 填充七个字段后，均无残留 `{{ owner.` 占位符。
- 浏览器本地渲染：使用 Edge Headless 检查空图片 URL 场景，横幅为深蓝底、头像为灰蓝圆形，没有裂图图标，姓名未被遮挡；使用可访问的示例图片 URL 检查两处背景图能显示。示例图片只用于内存渲染，没有写入模板。
- 未执行单元测试、集成测试、容器实跑、真实邮箱发信和生产验证。

## 7. Bug 定位和回退

- 若仍见裂图，先确认线上发送的是新版完整 HTML，检查是否有发信端另行插入 `<img>`。
- 若有图片却不显示，检查最终 HTML 中的 URL、公网可访问性和邮件客户端背景图支持情况。
- 回退：恢复横幅和头像的 `<img>` 结构及对应文档；不涉及数据库回滚。

## 8. 已知限制

旧版 Outlook 等邮件客户端可能仅显示纯色底，不保证显示 CSS/HTML 背景图片。若要求这些客户端也一定显示头像，需要发信端提供有效的默认图片 URL 并针对空值做条件渲染；当前仓库没有 TekMark 发信实现，无法在此修改该逻辑。
