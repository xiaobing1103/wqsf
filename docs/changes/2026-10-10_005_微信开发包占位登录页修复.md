## 1. 为什么修改

微信开发者工具打开 `dist/dev/mp-weixin` 后，登录页只显示 `pages/auth/login.wxml`，没有品牌区、微信登录和账号密码登录表单。源码与生产构建产物均完整，问题实际来自旧的 development watcher 没有把新增登录页重新编译到开发包，导致开发目录仍保留 64 字节的占位 WXML。

本次目标是重新生成可调试的微信 development 包，确认本地登录接口可用，并把这一类“源码正确但模拟器仍显示占位页”的排查方法写入维护文档。

## 3. 修改前后的逻辑

### 修改前

```text
旧 development watcher
  -> 新增登录页未完整生成
  -> dist/dev/.../login.wxml 只有占位文本
  -> 微信开发者工具只能显示 pages/auth/login.wxml
```

源码 `src/pages/auth/login.vue` 和 `dist/build/mp-weixin` 中的生产构建页面本身没有缺失，因此继续改 Vue 模板不能解决这个问题。

### 修改后

```text
停止旧 development watcher
  -> 在 apps/client-uni 执行 pnpm dev:mp-weixin
  -> dist/dev/mp-weixin 重新生成
  -> 微信开发者工具热刷新完整登录页
  -> 本地模拟微信登录调用 /auth/client/dev-login
```

重新生成后 `login.wxml` 为 3674 字节，包含“万企商服通”“微信登录”“账号登录”和 `local_client` 等完整页面内容。

## 7. Bug 定位和回退

- 再次出现占位文字时，先检查 `apps/client-uni/dist/dev/mp-weixin/pages/auth/login.wxml` 的大小和内容；如果只有约 64 字节并包含单行 `<text>pages/auth/login.wxml</text>`，说明 development 产物过期。
- 确认微信开发者工具导入的是 `dist/dev/mp-weixin`，不要混用 `dist/build/mp-weixin` 的旧项目窗口。
- 停止旧的 `pnpm dev:mp-weixin` 进程后，在 `apps/client-uni` 重新执行 `pnpm dev:mp-weixin`，等待 `DONE Build complete. Watching for changes...` 再回到开发者工具普通编译。
- 如果页面完整但登录失败，再检查后端 `8080`、Actuator Health、`.env.development` 和 `/auth/client/dev-login`，不要继续修改页面模板。
- 本次没有业务源码、接口或数据库变更，不需要代码或数据库回滚；若只回退文档，恢复本记录涉及的三份维护文档即可。

## 8. 已知限制

- `dist/dev/mp-weixin` 是本地生成目录；重新拉取项目或清理产物后必须重新执行 `pnpm dev:mp-weixin`。
- development watcher 必须在本地调试期间保持运行，否则后续源码变化不会自动同步到微信开发者工具。
- 本地模拟微信登录不等于真实微信授权；正式 AppID/AppSecret、合法域名、真实绑定和真机行为仍待上线前验证。
- 本次未执行后端单元测试、Testcontainers 集成测试、真机验证和生产验证，不能将本地模拟器结论扩大为这些层级已通过。
