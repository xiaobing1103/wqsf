# 客户操作菜单样式修复

> 日期：2026-10-09  
> 序号：007  
> 类型：修复 / 前端 / 文档  
> 状态：已完成

## 1. 为什么修改

客户资料列表点击三点图标后，操作菜单直接以表格单元格作为定位上下文。在当前浏览器布局下，菜单中的“编辑资料”等按钮横向散落到卡片外侧，并与分页按钮重叠，影响阅读和点击。

本次只修复客户操作菜单的定位与排列，不改变新增、查看、编辑、删除的业务逻辑。

## 3. 修改前后的逻辑

### 修改前

```text
表格单元格（定位上下文）
  -> 三点按钮
  -> 绝对定位菜单
  -> 菜单项受表格布局影响，横向溢出并覆盖分页
```

### 修改后

```text
固定宽度操作列
  -> 独立相对定位容器
     -> 三点按钮
     -> 左上方纵向菜单
        -> 查看详情
        -> 编辑资料
        -> 删除客户（仅超级管理员）
```

## 7. Bug 定位和回退

- 菜单仍错位时，先检查 `AdminLayout.vue` 的 `.company-action-anchor` 包装是否存在，再检查 `styles.css` 中 `.company-action-cell`、`.company-action-anchor` 和 `.action-menu`。
- 如果菜单被其他行遮挡，检查父容器是否新增了 `overflow: hidden`，以及菜单 `z-index` 是否被新的层叠上下文限制。
- 回退时恢复上述模板和样式改动即可；接口和数据库无需回退。

## 8. 已知限制

- 菜单仍依赖桌面浏览器的表格布局；宽度小于 720px 时页面沿用现有横向滚动表格方案。
- 本次不增加点击页面空白处自动关闭菜单的行为。
