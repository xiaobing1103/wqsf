## 7. Bug 定位和回退

- 容器无法启动时，先检查 `infra/docker-compose.yml`、`docker compose ps`和容器日志。
- MySQL 数据不符时，先核对 `wqsf_mysql_data` 卷、原 `infra_mysql_data` 卷和迁移前 SQL 备份。
- SeaweedFS 文件异常时，先核对 `wqsf_seaweedfs_data` 卷、`infra/seaweedfs-s3.json` 和 8333/9333/8888 端口。
- 回退时停止新路径容器，使用项目外备份恢复命名卷，或将目录移回原路径。
