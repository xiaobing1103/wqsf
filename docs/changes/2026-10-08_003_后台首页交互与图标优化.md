# 后台首页交互与图标优化

> 日期：2026-10-08
> 序号：003
> 类型：修复 / 前端
> 状态：已完成

## 1. 为什么修改

管理后台首页有三个明确的易用性问题：

1. 顶部的头像、“系统管理员”和“退出”共用同一个按钮，点击任何位置都会直接退出，无法看出操作边界。
2. 侧边栏“运营工作台”使用卡片和箭头表现成可点击入口，实际只是没有事件的静态 `div`。
3. 首页、侧边栏和顶部使用 `⌒`、`◇`、`⌕`、`◎`、`⇑`等 Unicode 图形字符，在不同系统字体下的造型与对齐不统一，也不能准确表达功能。

本次保持原有布局、颜色和 API 逻辑，只修正交互边界、操作反馈和图标语义。

## 3. 修改前后的逻辑

### 修改前

```text
点击头像 / 管理员姓名 / 退出文字
  -> 立即调用退出接口
  -> 返回登录页

点击“运营工作台”
  -> 无事件
  -> 页面无反应

图标
  -> Unicode 字符
  -> 形状依赖本机字体
```

### 修改后

```text
头像 + 管理员姓名
  -> 只展示登录身份
  -> 点击不产生注销或导航

独立退出按钮
  -> 打开页面内确认弹窗
  -> 取消：留在当前页
  -> 确认退出：调用既有退出接口

运营工作台
  -> 其他页面：返回 /dashboard
  -> 已在工作台：刷新工作台数据

图标
  -> 内置线性 SVG
  -> 统一尺寸、线宽、颜色和语义
```

## 7. Bug 定位和回退

- 点击身份区仍意外退出时，先检查 `AdminLayout.vue` 的 `.user-identity`、`.logout-button`和 `requestLogout`，再检查 `styles.css` 中两个区域是否发生覆盖。
- 工作台快捷入口无反应时，检查 `openWorkspace`、`nav`、Vue Router 和浏览器 Console。
- 图标空白或线条错乱时，检查 `AdminIcon.vue` 的 `name` 分支、SVG `viewBox` 和对应 CSS 尺寸。
- 回退时删除 `AdminIcon.vue`，恢复 `AdminLayout.vue` 中原图形字符和原退出按钮，并恢复 `styles.css` 的对应样式。不需要回退数据库或后端。
