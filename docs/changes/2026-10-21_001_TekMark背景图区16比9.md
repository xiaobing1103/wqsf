# TekMark 背景图区调整为 16:9

> 日期：2026-10-21  
> 序号：001  
> 类型：修复  
> 状态：已完成本地验证，待真实邮箱验证

## 1. 为什么修改

用户要求名片背景区域使用 16:9，原固定高度随屏幕宽度变化不能保持该比例。

## 2. 修改文件清单

| 文件 | 类型 | 修改内容 |
| --- | --- | --- |
| `tekmark-card.html` | 修改 | 移除固定高度，新增比例占位层和 MSO 高度回退 |
| `docs/03_前端设计与开发规范.md` | 修改 | 补充背景区域比例与邮件兼容说明 |
| `docs/changes/README.md` | 修改 | 顶部登记本次记录 |
| `docs/changes/2026-10-21_001_TekMark背景图区16比9.md` | 新增 | 本记录 |

## 3. 修改前后的逻辑

### 修改前

背景区域桌面高度 186px，手机高度 166px，图片区域不能始终保持 16:9。

### 修改后

背景单元格通过内部 `height:0;padding-top:56.25%` 占位层按宽度自适应为 16:9。保留动态背景字段、居中 cover 裁切、圆角、缺图底色及头像重叠。MSO 条件样式隐藏比例占位层，按桌面内容宽度回退至约 235px 高。

## 4. 接口、数据库和前端影响

- 接口、数据库、配置：无变化。
- 前端：仅独立 HTML 的背景区域高度调整；文字、链接和动态字段不变。

## 5. 目录结构变化

业务目录及关键入口无变化，仅新增本次常规变更记录。

## 6. 验证结果

- 本地 Chrome CDP 实测 320、375、517、900px 视口，背景区域宽高分别为 246×138.375、301×169.3125、417×234.5625、418×235.125，均为 16:9。
- 上述四种宽度均无横向溢出，脚本确认头像跨在封面底边，查看 517px 截图确认布局。
- 静态检查确认仅调整背景区域相关属性，固定文案、七个动态字段及链接保持不变；`git diff --check` 通过。
- 未执行单元测试、集成测试、容器实跑、真实邮箱或生产验证。

## 7. Bug 定位和回退

- 比例异常时检查发信平台是否保留 `.email-cover-ratio` 的行内百分比内边距，以及是否仍注入旧的固定高度。
- 回退时恢复背景单元格的 186px 高度、手机端 166px 覆盖，并删除比例占位层和本次新增的 MSO 比例回退样式；修改前 HTML 已备份到本机临时目录 `tekmark-design-check/tekmark-card-before-ratio.html`。

## 8. 已知限制

经典 Outlook 使用桌面尺寸回退，未执行真实邮箱测试。原图比例不为 16:9 时使用居中裁切填满区域，不会拉伸图片。
